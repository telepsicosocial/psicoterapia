4. **Conformidade Ética:**

## 🚀 Como Executar Localmente

Como o projeto é totalmente estático, basta abrir o arquivo `index.html` em qualquer navegador:

### Opção 1: Abrir diretamente
Basta dar um duplo clique no arquivo `index.html` ou arrastá-lo para a janela do seu navegador.

### Opção 2: Servidor HTTP simples (Node.js ou Python)
Se desejar testar via localhost:

```bash
# Com Python 3:
python3 -m http.server 8080

# Ou com Node.js (npx serve):
npx serve .
```

Acesse em seu navegador: `http://localhost:8080/`
